# ICORA Website

A responsive one-page website based on the supplied ICORA UI direction.

## Included
- `index.html`
- `styles.css`
- `script.js`
- `assets/icora-logo.svg`

## Run locally
Open `index.html` directly, or run a local server from this folder, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Notes
- The contact email is set to `info@icora.lk`.
- No phone number is displayed anywhere.
- Bootstrap 5, Bootstrap Icons, Google Fonts, and Unsplash imagery are loaded from CDNs.
- Replace the placeholder social links and policy links before production deployment.
